# USTA | أُسطى

واجهة Front-End عربية RTL لمنصة USTA للخدمات الفنية وخدمات السيارات والطوارئ.

## أهم التدفقات
- تسجيل حساب مرة واحدة: عميل أو فني أو Auto.
- حساب العميل له Dashboard مستقل: الخدمات، الطلبات، الفنيون المتاحون، الشات، المدفوعات، المفضلة والإعدادات.
- حساب الفني له Dashboard مستقل: الطلبات المطابقة لتخصصه فقط، حالة شغال الآن، الشات، Portfolio، التقييمات والأرباح.
- الفني لا يظهر للعميل إلا بعد تفعيل "شغال الآن" وتحديد نطاق العمل.
- طلب الخدمة يدعم العنوان اليدوي مع اقتراحات، أو GPS.
- الخريطة تعرض مقدمي الخدمة المطابقين والمتاحين فقط.
- تصميم Responsive للموبايل والكمبيوتر.
- Dark Mode محفوظ في المتصفح.

## التشغيل
يمكن فتح `index.html` مباشرة، أو نشر المشروع على GitHub Pages.

> ملاحظة: الحسابات والطلبات والشات وظهور الفني بين أجهزة مختلفة تحتاج Backend + Database + Realtime في النسخة الإنتاجية. النسخة الحالية Front-End Demo وتستخدم LocalStorage للتجربة داخل المتصفح.

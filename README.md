# USTA | أُسطى

واجهة Front-End تفاعلية جاهزة لـ GitHub Pages.

## التشغيل
ارفع محتويات هذا المجلد مباشرة إلى Repository، بحيث يكون `index.html` في الجذر، ثم فعّل GitHub Pages من Settings → Pages → Deploy from branch → main → /(root).

## الأدوار
- Client: طلب الخدمات، تحديد العنوان أو GPS، خريطة الفنيين المتاحين، الطلبات، الشات.
- Technician: طلبات التخصص فقط، Online + نطاق العمل، عمولة USTA 10%، Portfolio، أرباح وتقييمات.
- USTA Auto: مساحة مستقلة للونش وخدمات الطريق.

## ملاحظة
الشات الحقيقي بين أجهزة متعددة، Realtime GPS، الحسابات الآمنة، الدفع، وقاعدة البيانات تحتاج Backend/Realtime service. النسخة الحالية Front-End Demo.
